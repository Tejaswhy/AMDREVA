# 🎬 Hollywood Movie Analytics Dashboard

Hollywood Movie Analytics Dashboard is an interactive data analytics web application built using Streamlit, Pandas, and Plotly. The project analyzes a sample dataset of popular Hollywood movies and presents insights through interactive visualizations and statistical summaries. Users can explore movie information such as genre, ratings, vote counts, and release years through a clean and responsive dashboard interface.

The application provides genre-based filtering that allows users to view specific categories of movies and instantly update all analytics and visualizations. Key performance indicators (KPIs) display important statistics including the total number of movies, average movie rating, and highest rating available in the selected dataset. The dashboard also includes detailed analytical sections that highlight top-rated movies, genre distributions, average ratings by genre, movies with ratings above 8, and the highest voted movie.

Interactive Plotly visualizations are used to make the data more engaging and easier to understand. The dashboard features a bar chart for comparing movie ratings, a pie chart showing genre distribution, a scatter plot illustrating the relationship between votes and ratings, and a correlation heatmap that helps identify relationships between numerical attributes such as ratings, votes, and release years. These visualizations update dynamically based on user-selected filters.

The project is developed entirely in Python and demonstrates the practical use of data analysis and visualization libraries in building modern web-based analytics applications. It serves as a beginner-friendly example of dashboard development and can be extended further by integrating databases such as MySQL, connecting to movie APIs like IMDb, implementing recommendation systems, or adding user authentication features.

Technologies used in this project include Streamlit for web application development, Pandas for data manipulation and analysis, Plotly for interactive data visualization, and Python as the core programming language. The application can be run locally using Streamlit or deployed easily on platforms such as Streamlit Community Cloud, Render, Railway, or Hugging Face Spaces.
